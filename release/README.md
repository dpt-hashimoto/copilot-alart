# GitHub Copilot使用量のアラートツール

## 概要

GitHub Copilotの使用量を取得し、メール通知を行うツールです。

Spring Bootで作成しており、

- Web画面からの実行

に対応しています。


## 制約

* GitHubで2FA認証を設定している場合は対応しておりません。
* GitHubの画面に変更があった場合に動作しなくなる可能性があります。

## 主な機能

- GitHub Copilot 設定画面から使用量取得
- 使用率の表示
- メール送信
- Web画面からの実行

## 動作環境

- Docker(任意)
- Googlechrome

## 使い方

### Dockerインストール環境の場合

1. コマンドプロンプトを開く
2. インストールディレクトリに移動する ※bin,config等が存在するディレクトリ
3. 以下コマンドを実行し、Docker環境のMySQLとメールサーバを立ち上げる。

~~~
docker compose up -d --build
~~~

4. インストールディレクトリ/bin/start.batを実行する。
5. ブラウザで「127.0.0.1:28080」にアクセスし画面が表示されることを確認
6. 停止する際はインストールディレクトリ/bin/stop.batを実行する。

### Docker環境が無い場合

1. インストールディレクトリ/config/default/sqlite直下のファイルを、インストールディレクトリ/config直下に上書きコピー
2. コピーしたmail.propertiesに任意のメールサーバ情報を設定
3. インストールディレクトリ/bin/start.batを実行する。
4. ブラウザで「127.0.0.1:28080」にアクセスし画面が表示されることを確認
5. 停止する際はインストールディレクトリ/bin/stop.batを実行する。
